# Challenge 3 - Logging operazioni critiche

Sono stati aggiunti log applicativi per le operazioni critiche del sistema: creazione, modifica ed eliminazione articoli, oltre all’assegnazione e al cambio dei ruoli.

L’obiettivo è garantire tracciabilità delle azioni e migliorare accountability e non-repudiation.

La verifica finale ha confermato la generazione delle relative voci nel file `storage/logs/laravel.log`.
